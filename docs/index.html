// decimal de ponto fixo · bigint · duas APIs

CONTA EXATA, sem float.

Cada decimal é um bigint escalado: de 0 a 20 casas, nove modos de arredondamento e contexto imutável. Sem 0.30000000000000004 no meio do caminho — e sem dependência de runtime.

§ 01 — por quê

O float mente em silêncio.

fluxo — antes / depoisunified
--- a/float.js
+++ b/fixed.js
1- 0.1 + 0.2
2- 0.30000000000000004
3- (2.675).toFixed(2)
4- "2.67"
1+ new FixedPrecision("0.1").add("0.2").toString()
2+ "0.3"
3+ new FixedPrecision("2.675").scale(2, 4).toFixed(2)
4+ "2.68"

0.1 + 0.2 = 0.3

Em binário, 0.1 e 0.2 não têm representação finita. O fixed-precision soma inteiros escalados: com 8 casas, 1.23 vira 123000000. O resultado é o número que você escreveu.

contexto explícito

Casas e modo de arredondamento fazem parte do valor. create({ places: 2 }) congela um contexto imutável. A API de classes recusa misturar precisões; a funcional resolve pelo maior places.

um núcleo, duas APIs

fixed-precision para encadeamento e classes. fixed-precision-fns para funções puras, com um subcaminho por operação. As duas usam o mesmo código de valor.

§ 02 — primeiros passos

Três passos até a conta fechar.

01

Instale

Um pacote, sem dependências de runtime. A API funcional é um segundo pacote, opcional.

$ npm install fixed-precision
02

Congele um contexto

Para dinheiro, uma factory imutável: duas casas e o modo que você escolher. O padrão é places: 8 e HALF_UP.

const Money = FixedPrecision.create({ places: 2 });
03

Opere

Métodos aceitam string, number, bigint ou outra instância. Encadeie sem instanciar cada operando.

Money("19.99").mul("3").toString() // "59.97"

§ 03 — recursos

Construído como ferramenta de precisão.

FIXED(1) · Manual

01places 0–20

A escala é explícita e limitada. new FixedPrecision("1.23") guarda 123000000 com 8 casas; create({ places: 2 }) guarda 123.

029 modos

ROUND_UP, ROUND_DOWN, ROUND_CEIL, ROUND_FLOOR, ROUND_HALF_UP, ROUND_HALF_DOWN, ROUND_HALF_EVEN, ROUND_HALF_CEIL e ROUND_HALF_FLOOR. O padrão é HALF_UP (4).

03create()

Factories imutáveis: create({ places: 2, roundingMode: 6 }) congela o contexto. Mudar o padrão global depois não altera a factory.

04/minimal

A entrada enxuta: criação, aritmética, comparação, arredondamento, sqrt, estatística básica e formatação comum. Fora ficam trigonometria, logs, matrizes, frações, bitwise e combinatória.

05fns/add

Um subcaminho por operação em fixed-precision-fns. import { add } from "fixed-precision-fns/add" puxa só o grafo de add: 3,06 kB minificados e 1,24 kB gzip.

06pipe()

pipe, compose e partial compõem estágios tipados de ponta a ponta. As variantes *By fazem o mesmo bind com nome próprio.

07raw()

Operações escaladas (add, mul) validam o contexto. As raw (plus, times) operam direto no bigint. Use raw quando a escala já é conhecida.

08bigint

O valor interno é um bigint. raw() devolve o inteiro escalado. Um bigint na entrada é tratado como já escalado — veja o aviso no § 06.

0925 trig

sin, cos, tan, sec, csc, cot, as inversas, as hiperbólicas e as inversas hiperbólicas, com atan2. A precisão é medida contra referências de 45 dígitos.

100 deps

Nenhuma dependência de runtime. ESM + CJS + tipos TypeScript, sideEffects: false e builds minificados.

11imutável

Toda operação devolve um valor novo. Instâncias não mudam; contexto e escala fazem parte do valor.

12MIT

Licença MIT nos dois pacotes. Embuta em produto fechado, sem taxa e sem pegadinha.

§ 05 — funcional

Uma função, um subcaminho.

$ npm install fixed-precision-fns

ou npm add fixed-precision-fns — a camada funcional é um pacote separado, sem dependências de runtime.

money.ts 
import { createFactory } from "fixed-precision-fns/createFactory";
import { multiply } from "fixed-precision-fns/multiply";
import { stringify } from "fixed-precision-fns/stringify";

const Money = createFactory({ places: 2 });
stringify(multiply(Money("19.99"), "3")); // "59.97"
pipe.ts 
import { addBy } from "fixed-precision-fns/add";
import { multiplyBy } from "fixed-precision-fns/multiply";
import { stringify } from "fixed-precision-fns/stringify";
import { pipe } from "fixed-precision-fns/pipe";

pipe(addBy("2"), multiplyBy("3"), stringify)("1"); // "9"
119 subcaminhos

aritmética · relação · trigonometria · strings · lógica · combinatória · estatística · matrizes · frações · bitwise · constantes · composição

sem configure()

A API funcional não tem estado global mutável. O contexto padrão é congelado em 8 casas e HALF_UP; o contexto vem dos operandos, não do ambiente.

dados, não classes

As operações de valor devolvem dados simples — { ctx, value } ou um primitivo. Nada de protótipo, cache global ou ordem de import. A ponte com a API de classes é dataOf.

tree-shaking medido

Um entry por operação e sideEffects: false. O barrel também poda: import { add } fica em 3,06 kB min / 1,24 kB gzip. O orçamento é um teste em CI.

§ 06 — núcleo

O valor é um inteiro.

Com 8 casas, 1.23 é 123000000n. Somar é somar inteiros; dividir escala de volta. Nada de mantissa binária.

inside.ts 
const FP2 = FixedPrecision.create({ places: 2 });

FP2("1.23").raw();              // 123n
FP2("1.23").plus("2.00").raw(); // 323n
FP2("0.1").add("0.2").toString(); // "0.3"
FP2("1").div("3").toString();     // "0.33"

bigint é pré-escalado

new FixedPrecision(123n) não é 123. Com 8 casas, é 0.00000123. Use string ou number para valores literais; reserve bigint para valores já escalados.

leia o aviso completo ↗

escala

places define a escala, de 0 a 20. SCALE = 10^places. O valor bruto é sempre bigint.

contexto

{ places, roundingMode, SCALE, SCALENUMBER }. O contexto acompanha o valor; factories o congelam.

escalado × raw

add/mul validam e escalam. plus/times pulam a validação e operam no inteiro. Escolha raw só quando souber a escala.

o que é ULP

ULP aqui é uma unidade na última casa decimal (10^-places), não um bit. Em ângulos genéricos, a trigonometria fica a duas unidades da referência.

fixado no CI

O teste de tree-shaking falha se o grafo de add passar do orçamento. O CI roda lint, formato, testes, build e a checagem de exports.
